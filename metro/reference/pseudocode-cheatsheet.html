Pseudocode cheat sheet

From lessons 07–08. Python style is the default; C++ style only if a question asks for it.

Before you write lesson

  1. Inputs and outputs as a comment
  2. One example by hand
  3. Plan in 3–6 plain lines
  4. Write it, with good names
  5. Trace: your example + one edge case

Answer checklist

  • "Pseudocode (Python style)" written at the top
  • Input read, output printed
  • Variables initialised before loops
  • Loop bounds unambiguous (1 to n inclusive)
  • Edge cases: empty, zero, negative, one item
  • No division by zero
  • Functions return rather than print
  • Indentation consistent

x = input("prompt")        # read
print("Total:", total)     # write

    ...

    ...
else:
    ...

for i from 1 to n:          # inclusive
for i from n down to 1:

    return result

n % 2 == 0     # even
n // 10        # integer division
len(values)    values[0]    values[len-1]

Pattern skeletons lesson

# accumulate
total = 0
for each x in values: total = total + x

# count matching
count = 0
for each x in values:
    if condition(x): count = count + 1

# max (never start at 0)
best = values[0]
for each x in values:
    if x > best: best = x

# search: index or -1
for i from 0 to len(values) - 1:
    if values[i] == target: return i
return -1

# longest streak
if ok: run = run + 1; longest = max(longest, run)
else: run = 0

# product starts at 1
result = 1

C++ style equivalents

cin >> x;
cout << total << endl;
if (a > b) { ... } else { ... }
for (int i = 1; i <= n; i++) { ... }
while (x > 1) { ... }
int square(int n) { return n * n; }
int values[10];

Classic traps

  • max = 0 fails on all-negative data
  • result = 0 for a product
  • Printing inside the loop when one result is wanted
  • FizzBuzz: test the "both" case first
  • Swapping without a temp variable overwrites
  • Average before you know the total needs two passes
