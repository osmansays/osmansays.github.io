Glossary

Mathematics

Matrix · size (m × n)
A grid of numbers with m rows and n columns. aij is the entry in row i, column j.
Scalar
An ordinary number, as opposed to a matrix. kA is a scalar multiple.
Function · f(x)
A rule that turns an input x into one output.
Root · zero
A value of x where f(x) = 0; where the graph crosses the x-axis.
Quadratic
A function of the form ax² + bx + c with a ≠ 0. Its graph is a parabola.
Discriminant · D
b² − 4ac. Its sign tells you how many real roots a quadratic has.
Composition · f(g(x))
Apply g first, then f to the result.
Derivative · f′(x) · dy/dx
The slope of f at each point; the instantaneous rate of change.
Stationary point
A point where f′(x) = 0: a local maximum, minimum, or flat inflection.
Power · product · chain rule
The three derivative rules that cover the exam. See the math sheet.
Mean
Sum of values divided by how many there are.
Median
Middle value of the sorted data; mean of the two middle values if the count is even.
Mode
The most frequent value.
Outlier
A value far from the rest. Pulls the mean, not the median.
Frequency table
A list of values with how often each occurs.
Outcome · event
One possible result · a set of outcomes you care about.
Complement
"Not A". P(not A) = 1 − P(A).
Independent events
One happening doesn't change the probability of the other. Multiply for "and".
Mutually exclusive events
Cannot both happen. Add for "or".
With / without replacement
Whether a drawn item goes back before the next draw. Without replacement, the totals shrink.

Programming

Pseudocode
Program logic written for a human reader, in a code-like style without strict syntax.
Trace table
A table with one column per variable and one row per step, used to run code by hand.
Accumulator
A variable that builds up a result across a loop (a total, a count, a product).
Edge case
An input at the boundary of what's expected: empty list, zero, negative, one item, the largest value.
Off-by-one error
A loop that runs one time too many or too few, usually from unclear bounds.
Modulo · %
The remainder after division. n % 2 == 0 means n is even.
Integer division · //
Division that drops the fractional part: 7 // 2 = 3.
Function · return value
A named, reusable block that takes parameters and gives back a result.
Index
Position of an element in a list. Starts at 0 in both Python and C++.
