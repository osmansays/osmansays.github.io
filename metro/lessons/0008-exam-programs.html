Level 1 · decisions

1 · Positive, negative or zero

Read a number and print whether it is positive, negative or zero.

# input: number x   output: its sign as text
x = input("Enter a number")
if x > 0:
    print("positive")
elif x < 0:
    print("negative")
else:
    print("zero")

2 · Count the even numbers

Read how many numbers will follow (n), then read the n numbers and print how many were even.

# input: n, then n integers   output: count of even ones
n = input("How many numbers?")
even_count = 0
for i from 1 to n:
    x = input("Number")
    if x % 2 == 0:
        even_count = even_count + 1
print("Even numbers:", even_count)

Level 2 · loops over data

3 · Largest and smallest

Given a list of numbers, print the largest and the smallest. Handle an empty list.

# input: list values   output: max and min
if len(values) == 0:
    print("List is empty")
else:
    largest = values[0]
    smallest = values[0]
    for i from 1 to len(values) - 1:
        if values[i] > largest:
            largest = values[i]
        if values[i] < smallest:
            smallest = values[i]
    print("Largest:", largest, "Smallest:", smallest)

4 · FizzBuzz

Print the numbers 1 to 100, but print "Fizz" for multiples of 3, "Buzz" for multiples of 5, and "FizzBuzz" for multiples of both.

for i from 1 to 100:
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)

Level 3 · sequences and functions

5 · Fibonacci

Read n (n ≥ 1) and print the first n Fibonacci numbers: 0, 1, 1, 2, 3, 5, …

# input: n   output: first n Fibonacci numbers
n = input("How many terms?")
a = 0
b = 1
for i from 1 to n:
    print(a)
    next_term = a + b
    a = b
    b = next_term

Trace n = 6: prints 0, 1, 1, 2, 3, 5. ✓

6 · Primes below 50

Write a function is_prime(n) and use it to print all prime numbers below 50.

def is_prime(n):
    if n < 2:
        return False
    i = 2
    while i * i <= n:        # only test up to sqrt(n)
        if n % i == 0:
            return False
        i = i + 1
    return True

for n from 2 to 49:
    if is_prime(n):
        print(n)

Level 4 · strings and the hard Q5

7 · Palindrome

Read a word, build its reverse with a loop (no built-in reverse), and print whether it is a palindrome.

word = input("Enter a word")
reversed_word = ""
for i from len(word) - 1 down to 0:
    reversed_word = reversed_word + word[i]
print("Reversed:", reversed_word)
if reversed_word == word:
    print("Palindrome")
else:
    print("Not a palindrome")

Mention in a comment that you'd convert to lowercase first if "Anna" should count.

8 · Sensor monitor (Smart Industry Q5)

A list holds temperature readings from a machine, and a threshold is given. Print the average reading, how many readings were above the threshold, and the longest run of consecutive readings above it.

Test data: readings 22, 27, 29, 24, 30, 31, 33, 21 and threshold 25. Expected: average 27.125, above 5, longest run 3.

# input: list readings, number threshold
# output: average, count above, longest run above
if len(readings) == 0:
    print("No data")
else:
    total = 0
    above = 0
    run = 0
    longest = 0
    for each r in readings:
        total = total + r
        if r > threshold:
            above = above + 1
            run = run + 1
            if run > longest:
                longest = run
        else:
            run = 0                 # streak broken
    print("Average:", total / len(readings))
    print("Above threshold:", above)
    print("Longest run:", longest)
