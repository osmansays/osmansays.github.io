Derivatives of basic functions

A derivative is the slope of a function at each point, its rate of change. On the exam it's mostly mechanical: learn the power rule cold, then add the product and chain rules for the harder question.

Warm-up · from lesson 03

Solve x² − 7x + 10 = 0.

Product 10, sum −7 → −2 and −5. (x − 2)(x − 5) = 0 → x = 2 or 5.

The trick that makes the power rule cover everything

Rewrite roots and fractions as powers first: √x = x1/2, 1/x² = x−2. Then x1/2 → ½x−1/2 = 1/(2√x) and x−2 → −2x−3 = −2/x³.

Worked examples, easiest first

A · polynomial (the likely Q3)

f(x) = 3x⁴ − 2x² + 7x − 5

Each term separately: 3·4x³ = 12x³, −2·2x = −4x, 7x → 7, −5 → 0.

f′(x) = 12x³ − 4x + 7

B · slope at a point

Slope of f(x) = x³ at x = 2? Differentiate first, then substitute: f′(x) = 3x², f′(2) = 3·4 = 12.

C · product rule

f(x) = x²·eˣ. Let u = x² (u′ = 2x), v = eˣ (v′ = eˣ).

f′ = u′v + uv′ = 2x·eˣ + x²·eˣ = eˣ(x² + 2x)

D · chain rule

f(x) = (3x + 1)⁵. Outside: (·)⁵ → 5(·)⁴. Inside: 3x + 1 → 3. Multiply.

f′(x) = 5(3x + 1)⁴ · 3 = 15(3x + 1)⁴

More: Paul's Notes – Chain Rule.

E · stationary point (a likely Q5 twist)

Where is f(x) = x² − 6x + 5 flat? Set f′(x) = 0: 2x − 6 = 0 → x = 3. Then f(3) = 9 − 18 + 5 = −4. The point (3, −4) is a minimum (the parabola opens upward because the x² coefficient is positive).

Where marks get lost
  • Constant terms: the derivative of −5 is 0, not −5.
  • Substituting before differentiating. Always f′ first, then plug in.
  • Chain rule: forgetting to multiply by the inner derivative.

Practice

P1

Derivative of 5x³?

5 · 3x² = 15x².
P2

Derivative of 4x³ − 6x² + 2x − 9?

12x² − 12x + 2. The −9 disappears.
P3

f(x) = 2x³ − x. Find f′(1).

f′(x) = 6x² − 1, f′(1) = 6 − 1 = 5.
P4

f(x) = x² + 3x. Slope of the graph at x = 4?

f′(x) = 2x + 3, f′(4) = 11.
P5

f(x) = 4√x. Find f′(4).

4x1/2 → 2x−1/2 = 2/√x. At x = 4: 2/2 = 1.
P6

Chain rule: f(x) = (2x − 1)³. Find f′(1).

f′(x) = 3(2x − 1)² · 2 = 6(2x − 1)². At x = 1: 6 · 1 = 6.
P7

Product rule: f(x) = x · ln x. Find f′(1).

f′ = 1·ln x + x·(1/x) = ln x + 1. At x = 1: 0 + 1 = 1.
P8

Find the stationary point of f(x) = 2x² − 8x + 1.

f′(x) = 4x − 8 = 0 → x = 2. f(2) = 8 − 16 + 1 = −7. Point (2, −7), a minimum.
