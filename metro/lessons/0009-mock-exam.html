Q2 · function

(a) f(2) = 4 − 4 − 15 = −15.

(b) Product −15, sum −2 → −5 and +3: (x − 5)(x + 3) = 0 → x = 5 or x = −3. Formula check: D = 4 + 60 = 64, x = (2 ± 8)/2.

Q3 · derivatives

(a) f′(x) = 12x² − 12x + 2, f′(1) = 12 − 12 + 2 = 2.

(b) Chain rule: g′(x) = 3(x² + 1)² · 2x = 6x(x² + 1)².

Q4 · mean and median

(a) Sorted: 3, 4, 5, 6, 7, 9, 10, 12. Sum 56, n = 8 → mean 7. Median = (6 + 7)/2 = 6.5.

(b) Sum 81, n = 9 → mean 9. Sorted: 3, 4, 5, 6, 7, 9, 10, 12, 25 → median 7. The mean moved by 2, the median by 0.5: the mean includes the size of the outlier, the median only its position.

Q5 · probability

(a) 0.97³ = 0.912673 ≈ 0.913. (By hand: 0.97² = 0.9409; 0.9409 × 0.97 = 0.9409 − 0.028227 = 0.912673.)

(b) 1 − 0.912673 = 0.087327 ≈ 0.087.

(c) 2/10 · 1/9 = 2/90 = 1/45 ≈ 0.022.

(d) Defective then OK, or OK then defective: 2/10 · 8/9 + 8/10 · 2/9 = 32/90 = 16/45 ≈ 0.356. Check: P(both OK) = 56/90, and 56 + 2 + 32 = 90. ✓

P4 · count vowels
def count_vowels(text):
    count = 0
    for each ch in text:
        if lowercase(ch) in "aeiou":
            count = count + 1
    return count

line = input("Enter text")
print("Vowels:", count_vowels(line))

Lose a mark if upper case isn't handled, or if the function prints instead of returning.

P5 · best day and below-average days
# input: list production (one value per day)
if len(production) == 0:
    print("No data")
else:
    # pass 1: total and best day
    total = 0
    best_index = 0
    for i from 0 to len(production) - 1:
        total = total + production[i]
        if production[i] > production[best_index]:
            best_index = i
    average = total / len(production)
    # pass 2: count days below average
    below = 0
    for each p in production:
        if p < average:
            below = below + 1
    print("Best day:", best_index + 1)
    print("Days below average:", below)

Key points: the average is only known after the first pass, so counting needs a second pass; the day number is index + 1.
