Solving a function

"Solve a simple function" could mean three things: find a value, find where it equals something, or find where it hits zero. Learn all three and you're covered whichever wording appears.

Warm-up · from lesson 02

+=

2+(−2)=0, −3+4=1, 1+5=6, 0+(−1)=−1.

1 · Evaluate: find f(a)

Replace every x with the number, in brackets.

Example

f(x) = x² − 3x + 2. Find f(−2).

f(−2) = (−2)² − 3(−2) + 2 = 4 + 6 + 2 = 12

Without brackets you'd write −2² = −4 and lose the mark. The square applies to the whole −2.

2 · Solve f(x) = k for a linear function

Undo the operations in reverse order, doing the same thing to both sides.

Example

f(x) = 3x − 5. For which x is f(x) = 10?

3x − 5 = 10 → 3x = 15 → x = 5

Check: 3(5) − 5 = 10. ✓ Always plug your answer back in; it takes 10 seconds.

3 · Solve f(x) = 0 for a quadratic

The solutions are called roots or zeros: where the graph crosses the x-axis. A quadratic ax² + bx + c = 0 has 0, 1 or 2 real roots.

Fast way: factor

When a = 1, look for two numbers that multiply to c and add to b.

Example

x² − 5x + 6 = 0. Need: product 6, sum −5 → −2 and −3.

(x − 2)(x − 3) = 0 → x = 2 or x = 3

Special case: x² − 9 = 0 → x² = 9 → x = ±3. Don't forget the negative root.

Always-works way: the quadratic formula

x = −b ± √(b² − 4ac)2a

The part under the root, D = b² − 4ac, is the discriminant: D > 0 two roots, D = 0 one root, D < 0 no real roots. Reference: Paul's Online Notes – Algebra, "Quadratic Equations".

Example

2x² + 3x − 2 = 0, so a = 2, b = 3, c = −2.

  1. D = 3² − 4(2)(−2) = 9 + 16 = 25, and √25 = 5.
  2. x = (−3 ± 5) / 4
  3. x = 2/4 = 1/2 or x = −8/4 = −2

Two more shapes of "solve"

  • Where do two lines meet? Set them equal. 2x + 1 = −x + 7 → 3x = 6 → x = 2, then y = 2(2) + 1 = 5. Point (2, 5).
  • Composition f(g(x)): work inside out. Compute g first, feed the result into f.

Practice

P1

f(x) = 4x + 3. Find f(−2).

4(−2) + 3 = −8 + 3 = −5.
P2

f(x) = x² − 3x + 2. Find f(−1).

(−1)² − 3(−1) + 2 = 1 + 3 + 2 = 6.
P3

Solve 5x − 7 = 18.

5x = 25 → x = 5.
P4

Solve x² − 9 = 0. Give both roots separated by a comma.

x² = 9 → x = 3 or x = −3.
P5

Solve x² + x − 12 = 0 by factoring.

Product −12, sum +1 → +4 and −3. (x + 4)(x − 3) = 0 → x = −4 or x = 3.
P6

Solve 3x² − 2x − 1 = 0 with the formula. Fractions like −1/3 are fine.

a=3, b=−2, c=−1. D = 4 + 12 = 16, √D = 4. x = (2 ± 4)/6 → x = 1 or x = −1/3.
P7

How many real roots does x² + 2x + 5 = 0 have?

D = 2² − 4(1)(5) = 4 − 20 = −16 < 0. No real roots: the parabola never touches the x-axis.
P8

Where do y = 3x − 4 and y = x + 2 intersect?

3x − 4 = x + 2 → 2x = 6 → x = 3, y = 3 + 2 = 5.
P9

f(x) = 2x − 1, g(x) = x². Find f(g(3)) and g(f(3)).

g(3) = 9, f(9) = 17. f(3) = 5, g(5) = 25. Order matters.
