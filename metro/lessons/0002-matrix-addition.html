Matrix addition

The exam's first math question: "calculate the sum of two matrices." It's the easiest mark on the paper, so the only goal is to never drop it to a sign slip.

Warm-up · from lesson 01

Which sections get graded?

Only the first two answered. Leave the other two blank.

The idea in one line

A matrix is a grid of numbers with a size rows × columns. Two matrices can be added only if they have the same size, and you add them position by position.

+=

The entry in row i, column j is written aij. So (A + B)ij = aij + bij. See Khan Academy: Matrices for the same rule with short videos.

Worked example

+

  1. Check sizes: both 2 × 2. Allowed.
  2. Top-left: 2 + 4 = 6. Top-right: −1 + 5 = 4.
  3. Bottom-left: 0 + (−2) = −2. Bottom-right: 3 + 1 = 4.

=

Three relatives the exam can slip in

  • Subtraction A − B: same rule, subtract position by position. Watch double negatives: 3 − (−2) = 5.
  • Scalar multiple kA: multiply every entry by k. Then combinations like 3A − B are just two easy steps.
  • Solve for X in X + A = B: then X = B − A, exactly like ordinary numbers.

Addition is commutative (A + B = B + A), so order doesn't matter. Multiplication is a different story, see the bonus at the end.

Where marks get lost
  • Copying a minus sign wrong. Circle negative entries before you start.
  • Adding matrices of different sizes. The answer is "not defined", and that is the correct answer.
  • In kA, multiplying only the first row.

Bonus: matrix multiplication (not in the spec, 5 minutes)

The invitation only lists the sum. If a Q5 does go further, the rule is row × column: entry (i, j) is row i of A dotted with column j of B. A must have as many columns as B has rows, and AB ≠ BA in general.

Bonus

·=

Top-left = (1)(0)+(2)(1) = 2. Top-right = (1)(1)+(2)(0) = 1. Bottom-left = (3)(0)+(4)(1) = 4. Bottom-right = (3)(1)+(4)(0) = 3. This matrix swaps the columns.
